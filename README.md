Password Generator
A simple yet powerful password generator built with React and styled with Tailwind CSS. This web application allows users to create secure, customizable passwords with various options.

Features :
1.Generate random passwords with a single click
2.Customize password length (9-24 characters)
3.Include or exclude numbers
4.Include or exclude special characters
5.One-click copy to clipboard functionality
6.Visual feedback when password is copied

Technologies Used
1.React - For building the user interface
2.Vite - Development environment
3.Tailwind CSS - For styling
4.Modern JavaScript (ES6+)

Project Structure
The project follows a standard Vite + React structure with Tailwind CSS integration.

App.jsx - Main application component
main.jsx - Entry point of the React application
index.css - Global styles with Tailwind imports
public - Static assets
